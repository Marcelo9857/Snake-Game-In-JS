# Snake-Game-In-JS
Primeiro Jogo da Cobrinha desenvolvido em javascript
Jogo criado para apresentação do colégio aberto no COTUCA.
não utilizei canvas no desenvolvimento.
Pensei em criar o jogo usando um sistema de plano carteziano, com uma grade de 20px por 20px;
O mapa do jogo é uma div enorme, onde a cobrinha pode se mover livremente.
Para centralizar a cobrinha no centro, pensei em movimentar o mapa em sentido contrário ao movimento da cobrinha.
Criei "tesouras" inimigas para treinar um pouco da lógica da perseguição da cobrinha.
Realizei testes de colisões através de posições x,y em arrays para os item do jogo.
Pretendo criar uma versão 2.0 com servidor "multiplayer" em node.js
